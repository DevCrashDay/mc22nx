Midnight Club II for Nintendo Switch

Drop your own copy of the game (USA, SLUS-20209) to get the Switch homebrew files. Everything happens in this browser tab: the ISO is never uploaded.

Drop the .iso here or click to choose it

Put it on the Switch

  1. Unpack mc22nx.zip to the root of the SD card: it holds switch/mc22nx.nro and the folder mc2/.
  2. Copy your ISO into that folder as sdmc:/mc2/mc2.iso (3.2 GB; FAT32 is fine, the file is under 4 GB).
  3. Start the homebrew menu through a game (hold R while starting any game) so the port gets the full memory, and run mc22nx.

Saves go to sdmc:/mc2/mc2.ps2. An env.txt / args.txt in mc2/ can change settings (see the repository).

How this works

  • The page reads only the game's main program (SLUS_202.09) from the ISO and checks that it is the expected version.
  • The Switch build ships encrypted; the key is derived from that file, so it opens only with the game itself.
  • Source code, findings and how to build it yourself: github.com/DevCrashDay/mc22nx.
